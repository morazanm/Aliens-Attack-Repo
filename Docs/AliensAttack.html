1 Data Definitions🔗

syntax

IMAGE-WIDTH

The maximum width of the image is 30 pixels.

syntax

IMAGE-HEIGHT

The maximum height of the image is 30 pixels.

syntax

MAX-CHARS-HORIZONTAL

The maximum amount of character images that fit horizontally is 20.

syntax

MAX-CHARS-VERTICAL

The maximum amount of character images that fit vertically is 15.

syntax

ci

A ci is a character image has dimensions which are at most IMAGE-WIDTH x IMAGE-HEIGHT pixels.

syntax

image-x

An image-x is an integer in [0..(sub1 MAX-CHARS-HORIZONTAL)].

syntax

image-y

An image-y is an integer in [0..(sub1 MAX-CHARS-VERTICAL)].

syntax

scene

A scene is a (MAX-CHARS-HORIZONTAL * IMAGE-WIDTH) x (MAX-CHARS-VERTICAL * IMAGE-HEIGHT) image.

syntax

rocket

A rocket is an image-x.

syntax

key

A key is either:
1. "right"
2. "left"
3. " "
4. Not "right", "left", or " ".
