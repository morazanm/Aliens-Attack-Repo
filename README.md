# Aliens Attack
A teachpack for Aliens Attack.

## Installation
The teachpack can be installed using the following methods: 

### Using DrRacket's Package Manager
![Racket Package Manager Install](docs/Media/AliensAttack-Install-ezgif.gif)

### Using raco from the CL
```bash
raco pkg install https://github.com/morazanm/Aliens-Attack-repo.git
```

## Documentation
![How to get to the documentation](docs/Media/AliensAttack-Docs-ezgif.gif)

## Getting Started
Once the Aliens Attack teachpack is installed you use:
```racket
(require APS-Aliens-Attack)
```
